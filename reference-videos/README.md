# reference-videos

A library of short-form reels to learn editing style from. The decoded grammar is in
[`STYLE-SPEC.md`](STYLE-SPEC.md); frame contact sheets are in `_sheets/`.

The `.mp4` files are third-party content owned by their creators and are **git-ignored** — download them yourself.
Point a project at one as a style reference with `style.from_reference: true` and `references: [{src: ...}]`.
